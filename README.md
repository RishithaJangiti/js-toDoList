# To-Do List App

A simple To-Do List application built using JavaScript DOM manipulation.

## Features
- Add a task using input box
- Display tasks dynamically on the page
- Delete individual tasks
- Clear input after adding task

## Technologies Used
- HTML
- JavaScript (DOM)

## How It Works
1. Type a task in the input field
2. Click the **Add task** button
3. The task appears in the list
4. Click **Delete** to remove a task

## Learning Purpose
This project was created to practice:
- DOM manipulation
- Creating elements dynamically
- Event listeners
- Handling user input
- Basic CRUD operations in JavaScript

## How to Run
1. Download or clone the repository
2. Open `toDoList.html` in any web browser
3. Start adding tasks
